## 🚀 Featured Projects

### 📡 Real-Time Crowd Management System
A full-stack MERN app that monitors and visualizes campus crowd density across **9 zones** from live network activity data. A Node.js/Express backend runs **DBSCAN clustering** on concurrent data streams and pushes updates to a React dashboard every **5 seconds** over Socket.IO.
`React` `Node.js` `Express` `MongoDB` `Socket.IO` `DBSCAN`

### 💬 Product Review Insights API
A production-grade Flask REST API that turns raw review datasets into structured **sentiment, pros, and cons** using a hallucination-free NLP pipeline. Batched inference (DeBERTa, DistilBERT), caching, and async processing keep responses **under 100ms**.
`Flask` `Python` `DeBERTa` `DistilBERT` `NLP`

### 🌉 SIH Bridge: Edge AI Structural Health Monitoring
An edge-AI system on **ESP32 + TensorFlow Lite Micro** that extracts **29 multi-sensor features** for on-device damage prediction. A FastAPI/WebSocket backend syncs sensor nodes, runs PINN-based inference, and broadcasts live structural health updates.
`ESP32` `TensorFlow Lite Micro` `FastAPI` `WebSockets` `PINN`
